
# 🎈 Golden Balloon Android

Port experimental de **Golden Balloon** para dispositivos Android, con soporte para:

- ✅ ARM64
- 🧪 ARMv7
- 🟢 OpenGL ES
- 🟣 Vulkan experimental
- 🌐 Multijugador online experimental
- 🎮 Controles adaptados para Android
- ⚡ Mejoras de rendimiento y compatibilidad

> ⚠️ Este proyecto continúa en desarrollo y pueden existir errores dependiendo del dispositivo, GPU, controlador o versión de Android.

---

## 📥 Descargas

Puedes descargar las versiones disponibles desde:

**[GitHub Releases](https://github.com/cristhiantey/goldenballoon-android-arm64/releases/tag/v0.4-android)**

## 🐛 Reportar errores

Si encuentras algún problema, incluye:

- Modelo del dispositivo
- Procesador / SoC
- GPU
- Versión de Android
- ARM64 o ARMv7
- OpenGL ES o Vulkan
- Descripción del error
